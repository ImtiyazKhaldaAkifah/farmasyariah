# 💊 Farmasyariah 2.0
### AI-Powered Halal Pharma Supply Chain & Embedded Islamic Financing

Ekosistem digital B2B yang memberdayakan Apotek UMKM melalui AI, efisiensi rantai pasok, dan pembiayaan syariah yang berkeadilan.

## 🚀 Fitur Utama Prototipe
1. **Scan & Expired Tracker:** Pencatatan stok dan pelacakan tanggal kedaluwarsa obat via barcode.
2. **Smart Restock (AI):** Prediksi kebutuhan stok berdasarkan pola penjualan.
3. **Akad Murabahah (Syariah):** Simulasi pembiayaan pengadaan obat bebas riba.
4. **Dashboard PBF:** Integrasi *real-time* antara Apotek dan Pedagang Besar Farmasi (PBF) untuk pengadaan dan retur obat.

## 🛠️ Teknologi
* HTML5
* CSS3 (Vanilla)
* JavaScript (Vanilla)
